# TopoSeason — V1 prototype

Prototype mobile-first d'une application de planification de saison de course.

## V1 incluse
- Calendrier annuel et objectifs de course
- Matching local de courses de démonstration
- Distinction Index / classique / route / trail
- Recherche et filtres
- Favoris / veille des inscriptions
- Préférences de rayon de recherche
- Géolocalisation opt-in côté navigateur
- Persistance locale via localStorage

## Important
Les courses, dates et statuts affichés dans cette V1 sont des données de démonstration destinées à valider l'expérience utilisateur. La prochaine étape consiste à brancher des sources de courses autorisées, un calcul routier réel et des notifications serveur.
